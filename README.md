# Sales Heatmap Demo 🗺️

## Overview

This project demonstrates a Python-based workflow for transforming sample sales data into interactive geospatial dashboards, heatmaps, time-series visualizations, and performance charts.

## Purpose

The goal of this project is to show how geospatial analysis and business intelligence can help identify regional sales patterns, emerging markets, and geographic performance trends.

## Skills Demonstrated

- Python scripting
- Pandas data preparation
- Plotly visualization
- Interactive HTML dashboard generation
- Geospatial business analysis
- Time-series animation
- GitHub portfolio documentation

## Technology Stack

- Python
- Pandas
- Plotly Express
- HTML/CSS
- ArcGIS Pro

## Repository Structure

- `src/` - Python scripts
- `notebooks/` - Jupyter notebooks
- `outputs/` - sample generated dashboards, charts, and animations
- `sample_data/` - sanitized sample data
- `screenshots/` - preview images for documentation
