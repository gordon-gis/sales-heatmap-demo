# Sales Heatmap Generator 🗺️

**Live Demo:** [Gordon GIS](https://www.gordongis.com/)

## 🚀 Overview
This tool automates the process of visualizing sales data across the US. It takes raw CSV logs and transforms them into:
- 📊 **Interactive Dashboards** (HTML)
- 🎥 **Time-Series Animations** (MP4)
- 📈 **Competitive Bar Charts** (Plotly)

## 🛠️ Technology Stack
- **Python** (Pandas, Plotly Express)
- **ArcGIS Pro** (arcpy)
- **HTML/CSS** (Dashboard layout)
